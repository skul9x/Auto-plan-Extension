## 🔴 Critical Issues (Phải sửa ngay)

### 1. Cửa hậu Bridge Server mở toang cho trang web bên ngoài tiêm lệnh (Drive-by AI Injection / RCE)
- **File**: `src/bridgeServer.ts` (Dòng 581, dòng 959-984)
- **Triệu chứng kỹ thuật**: 
  - `res.setHeader('Access-Control-Allow-Origin', '*');` cho phép bất kỳ website nào truy cập cross-origin.
  - Endpoint `POST /autoplan-command` nhận prompt và cho vào hàng đợi thực thi tự động mà **không có Token xác thực, Secret Header hay Origin Verification**.
  - Endpoint `GET /autoplan-status` làm lộ đường dẫn thư mục nhạy cảm (`workspacePath`, `workspaceName`).
- **Nguy hiểm (Ngôn ngữ đời thường)**:
  - Nếu anh đang bật VS Code và mở một trang web bất kỳ trên trình duyệt (Chrome, Edge, Firefox...), trang web đó có thể ngầm gửi lệnh tới máy tính của anh qua cổng `127.0.0.1:27182`.
  - Website độc hại có thể ép AI chạy các lệnh xóa file, đánh cắp mật mã hoặc cài mã độc vào máy mà anh không hề hay biết!
- **Cách sửa**:
  1. Loại bỏ hoàn toàn header `Access-Control-Allow-Origin: *` hoặc từ chối mọi request có header `Origin` trỏ tới website ngoài (`http://`, `https://`).
  2. Bổ sung cơ chế **Bridge Secret Token**: Mỗi khi extension khởi động, sinh một mã bí mật ngẫu nhiên (`crypto.randomUUID()`). Mọi request gửi tới Bridge Server bắt buộc phải có header `X-Bridge-Token: <token>` hoặc `Authorization: Bearer <token>`.
  3. Từ chối thực thi các lệnh từ `POST /autoplan-command` nếu không đúng Token bảo vệ.

### 2. Nguy cơ nâng quyền Root bất hợp pháp khi thực thi lệnh elevated (`pkexec` / `osascript`)
- **File**: `src/workbenchInjector.ts` (Dòng 149, dòng 237, dòng 293)
- **Triệu chứng kỹ thuật**:
  - `buildLinuxElevationCommand` tạo lệnh: `pkexec bash -c "cp '${safeTmp}' '${safeTarget}' && chmod 644 '${safeTarget}'"`
  - Việc bao bọc trong chuỗi kép `bash -c "..."` khiến bash vẫn diễn giải và thực thi các ký tự `$()` hoặc dấu backtick bên trong `${safeTarget}` hoặc `${safeTmp}` dưới quyền **root**.
  - Tương tự trên macOS: `osascript -e 'do shell script "...${cmd}..." with administrator privileges'`.
- **Nguy hiểm (Ngôn ngữ đời thường)**:
  - Lệnh này chạy với quyền Quản trị viên cao nhất (Root / Administrator).
  - Nếu tên đường dẫn file chứa ký tự đặc biệt do kẻ tấn công cài cắm, hệ thống sẽ thực thi ngầm đoạn mã đó với quyền Root, dẫn đến việc hacker chiếm trọn quyền kiểm soát hệ điều hành.
- **Cách sửa**:
  - Không truyền chuỗi nội suy vào `bash -c "..."`.
  - Trên Linux, gọi trực tiếp `pkexec cp <src> <dst>` và `pkexec chmod 644 <dst>` theo dạng tham số rời rạc hoặc script được cách ly chặt chẽ.
  - Kiểm tra và khử độc (sanitize/whitelist) nghiêm ngặt đường dẫn file trước khi gửi vào cơ chế elevation.

### 3. Tiêm lệnh PowerShell qua cơ chế sao chép Clipboard trên Windows (Command Injection)
- **File**: `src/keyboardManager.ts` (Dòng 486-487)
- **Triệu chứng kỹ thuật**:
  ```typescript
  const escapedText = text.replace(/'/g, "''");
  await execAsync(`powershell -NoProfile -NonInteractive -Command "Set-Clipboard -Value '${escapedText}'"`);
  ```
  Hàm `replace(/'/g, "''")` chỉ thay thế dấu nháy đơn, nhưng lệnh `powershell -Command "..."` lại được bọc bằng dấu **nháy kép** `"`!
- **Nguy hiểm (Ngôn ngữ đời thường)**:
  - Nếu nội dung prompt hoặc văn bản cần sao chép chứa dấu nháy kép `"` hoặc cú pháp PowerShell như `$(calc.exe)`, chuỗi lệnh sẽ bị phá vỡ và PowerShell sẽ thực thi ngay lập tức đoạn mã độc đó.
- **Cách sửa**:
  - Truyền dữ liệu text qua Standard Input (`stdin`) thay vì nhét trực tiếp text vào chuỗi dòng lệnh `-Command`.
  - Hoặc mã hóa 100% bằng Base64 (như nhánh ưu tiên dòng 481-483) và không dùng nhánh fallback ghép chuỗi không an toàn.

## 🟡 Warnings (Nên sửa)

### 1. Mặc định tự động duyệt quyền (Auto-Approve Dangerous Permissions)
- **File**: `src/config.ts` (Dòng 58, 103) & `media/autoplan-dom-bridge.js`
- **Chi tiết**: `autoApprovePermissions` mặc định là `true`. DOM bridge sẽ tự động tìm và click các nút "Allow", "Accept", "Execute" của IDE.
- **Nguy hiểm**: Giảm thiểu sự cảnh giác của người dùng. Nếu có prompt injection, người dùng sẽ không có cơ hội từ chối câu lệnh nguy hiểm.
- **Khuyến nghị**: Nên hiển thị cảnh báo rõ ràng cho người dùng hoặc chỉ tự động duyệt với các quyền đọc an toàn, không tự động duyệt lệnh terminal can thiệp sâu.

### 2. Tạo file tạm không an toàn trong thư mục chia sẻ `/tmp` (Symlink Race Condition)
- **File**: `src/workbenchInjector.ts` (Dòng 225)
- **Chi tiết**: Sử dụng `path.join(os.tmpdir(), ...)` và `fs.writeFileSync` mà không dùng cờ độc quyền (`O_EXCL` / `wx`).
- **Nguy hiểm**: Trên máy chủ có nhiều người dùng (multi-user Linux), kẻ xấu có thể tạo symlink sẵn để ghi đè file của người khác khi lệnh elevated chạy.
- **Khuyến nghị**: Tạo thư mục tạm riêng biệt với quyền phân quyền `0700` (`fs.mkdtempSync`) trước khi ghi file tạm.

### 3. Ghép chuỗi lệnh Shell trực tiếp thay vì truyền mảng tham số (`execSync`)
- **File**: `src/keyboardManager.ts` (Dòng 138, 141, 150, 169, 179, 183)
- **Chi tiết**: Lệnh `xdotool getwindowname ${winId}` và `ps -p ${pid} -o comm=` dùng chuỗi ghép thay vì `execFileSync('xdotool', ['getwindowname', winId])`.
- **Khuyến nghị**: Chuyển toàn bộ sang `execFile` / `execFileSync` với mảng tham số để triệt tiêu hoàn toàn nguy cơ shell injection.

### 4. Các gói phát triển (`devDependencies`) chứa lỗ hổng bảo mật đã biết
- **File**: `package.json`
- **Chi tiết**: `npm audit` phát hiện 7 lỗ hổng (3 High, 3 Moderate):
  - `serialize-javascript` (High - RCE via RegExp.flags)
  - `linkify-it` (High - ReDoS)
  - `mocha` / `diff` (DoS)
- **Khuyến nghị**: Chạy cập nhật bản vá cho các gói testing và build tool.

## 🟢 Suggestions (Tùy chọn nâng cao)

1. **Khóa Origin nghiêm ngặt cho Bridge**: Chỉ cho phép các request nội bộ không có Origin (từ extension) hoặc Origin xuất phát từ VS Code Webview (`vscode-webview://`).
2. **Lưu trữ Secrets chuẩn VS Code API**: Sử dụng `vscode.SecretStorage` cho bất kỳ API key, token truy cập nào nếu có mở rộng trong tương lai thay vì lưu vào configuration hay file text thường.
3. **Audit Logging bảo mật**: Ghi log lại mọi request gửi tới `POST /autoplan-command` kèm IP nguồn và client identity để lập trình viên dễ dàng phát hiện khi có hành vi bất thường.
