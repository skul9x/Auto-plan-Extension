## 🔴 Triệu chứng Nguy Kịch (Critical Issues - Cần cấp cứu)

### 1. ⚠️ Cảnh báo Node.js Deprecation `[DEP0169]` do sử dụng `url.parse()` cũ
- **Vị trí:** [`src/bridgeServer.ts`](file:///d:/skul9x/Auto-plan-Extension-main/src/bridgeServer.ts#L512)
- **Triệu chứng kỹ thuật:**
  ```typescript
  const parsedUrl = url.parse(req.url || '', true);
  ```
  Khi chạy trên Node.js 20+ (runtime của VS Code mới), console liên tục in cảnh báo:
  `[DEP0169] DeprecationWarning: url.parse() behavior is not standardized and prone to errors that have security implications. Use the WHATWG URL API instead.`
- **Hậu quả đời thường:**
  - Làm ô nhiễm log runtime của extension.
  - `url.parse` cũ tiêu tốn nhiều CPU hơn và không chuẩn hóa theo tiêu chuẩn WHATWG URL API mới, tiềm ẩn rủi ro phân tích sai query string hoặc hostname khi port discovery diễn ra liên tục.
- **Phác đồ điều trị:**
  - Thay thế `url.parse(req.url, true)` bằng `new URL(req.url || '', 'http://127.0.0.1')`.
